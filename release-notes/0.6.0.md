## v0.6.0 - Co-op Battle Tower

### Android players: read this first
- **Move your save before updating.** This version cannot install over 0.5.x. On your phone, open Options > Saves and send your save to your PC (or export a save file), uninstall the old app, install `pkmnPvE-0.6.0.apk`, then bring the save back.
- **Future updates install normally.** From now on every APK installs over the last one and keeps your save.

### Battle Tower
- **The Roguelite is now called the Battle Tower** everywhere: the menu, Home, missions, achievements and your trainer card.
- **New: Co-op Battle Tower.** Open an online room with a friend and the host can start a run for both of you. You each pick a starter and climb the same floors with your own team of up to 3.
- **Bosses and villains are fought together.** Once you both reach one, you fight it in doubles with both teams on the same side, and each of you picks for your own Pokemon.
- **One team down ends the run for both.** If either team is wiped out, the run is over, and each of you gets your rewards.
- **Co-op runs are saved.** Leave the room and carry on later with the same friend.

### Merging and Max Raids
- **Merging now opens with Max Raids.** Merging duplicates unlocks when you beat Boss Giovanni. Stars you have already earned stay.
- **More Gigantamax raid bosses.** Pikachu, Eevee, Meowth and Duraludon can now appear in their Gigantamax forms.

### New players
- **Welcome guide.** A short tour of the game now opens before your first starter. You can reopen it any time from Options > About.

### Saves
- **Google Drive backups are gone.** Use Send to another device or Save file in Options > Saves instead. Both work between PC and phone.

### Playing online
- **Clearer connection errors.** If a room cannot connect, the game now says so after 20 seconds and explains why. School, work and some mobile networks block direct connections, so it suggests trying home Wi-Fi.
- **Rooms stay open.** A room that briefly loses the matchmaking server reconnects, so its code keeps working.

### Options
- **New Mobile screen size (PC).** Plays the phone layout in a phone-shaped window.
- **New About section.** Shows the fan-game notice, the welcome guide, sprite credits and a Report a bug button.
- **Error log (PC).** Errors are now saved to `save/logs/errors.log`. Open log folder takes you there, so you can attach the file to a bug report.
- **Sprite credits.** The trainer sprite artists are credited in Options and in the trainer sprite picker.

### Smaller changes
- **Bottle Caps** now say they are only good for Fling or selling.
- **The login screen** shows the fan-game notice.
