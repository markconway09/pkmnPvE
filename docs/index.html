pkmnPvE

A Pokémon battle game for Windows, built on the Pokémon Showdown battle engine: catch and train a box of Pokémon, work through gym leaders, the Elite Four and the Champion, take on Roguelite runs, and try your luck at the Game Corner.

Download

Get the latest version from the releases page - download the zip, unzip it anywhere and run pkmnPvE.exe. The game updates itself from Options.

Cloud saves

Players can optionally connect their own Google Drive to keep a copy of their save and bring it back on another computer. The game only uses a hidden folder in Drive that it alone can see, and never reads anything else. See the privacy policy for exactly what is stored and where.

Source and support

The game's source code is on GitHub. Questions, bugs and requests: open an issue.
