pkmnPvE

A Pokémon battle game for Windows, built on the Pokémon Showdown battle engine: catch and train a box of Pokémon, work through gym leaders, the Elite Four and the Champion, take on Battle Tower runs, and try your luck at the Game Corner.

Download

Get the latest version from the releases page - download the zip, unzip it anywhere and run pkmnPvE.exe. The game updates itself from Options. On Android, download the .apk from the same page and open it (your phone will ask you to allow installs from your browser).

"Windows protected your PC"

The first time you run the game, Windows may show a blue Windows protected your PC box. It appears for any program that isn't signed with a paid certificate, which a free fan game isn't - it doesn't mean anything was found in the game. Click More info, then Run anyway. You only need to do this once. If you'd rather check first, the game's full source code is on GitHub (below).

Source and support

The game's source code is on GitHub. Questions, bugs and requests: open an issue.
